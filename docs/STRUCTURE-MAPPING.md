# Structure Mapping — Part 2 Reorganization

> **Generated by:** `scripts/audit_file_structure.py` + manual analysis
> **Source roadmap:** `docs/ROADMAP-v0.54-to-v1.0.md` Part 2
> **Current state:** 189 JS files (116 versioned), 127 CSS files, 37 Python files

## Rules

1. Any file whose name matches `*-vNN.{js,css,py}` **must be renamed** to a version-free name.
2. Any two files with overlapping symbol sets get **merged**.
3. Any file over 1,000 lines gets **split** by concern.
4. Any Python module over 800 lines gets **split** by route group.
5. `git mv` preserves history — never use plain `mv`.
