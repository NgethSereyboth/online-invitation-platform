## Probe legend

`probe <status>` is a live GET against a running backend with a probe slug; `/ <status> with slash` is the same path with a trailing slash. A 401/403 pair on both forms says nothing about routing (auth rejects before dispatch); only a differing pair does. Routes that generate artefacts are never probed.
