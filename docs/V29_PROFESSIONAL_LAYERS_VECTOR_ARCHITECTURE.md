# V29 Professional Layers and Vector — Architecture Plan Only

V29 should extend the normalized scene graph with a truly nested layer tree, clipping and layer masks, adjustment layers, smart objects, linked components, vector paths, pen editing, boolean shape operations, richer guides, and multi-artboard behavior. Every mutation must remain a typed command with one-step transactional history, editor/public parity, strict CSP, Khmer support, permissions, accessibility, lazy loading, and route budgets. No V29 implementation is included in V28.0.
