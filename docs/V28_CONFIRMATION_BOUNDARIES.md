# V28.0 Confirmation and Permission Boundaries

## Automatically eligible

Only reversible, project-local, low-risk edits may auto-apply, and only when the authenticated user explicitly enabled that preference. Revision, fingerprint, page, target, and permission checks still apply.

## Explicit target confirmation

Medium-risk plans require the user to confirm the exact invitation, pages, object IDs, and effects. Examples include page creation/reordering, palettes, brand kits, asset insertion, exports, tidy layout, background removal, and event/schedule replacement.

## Destructive or external confirmation

The following require a separate final confirmation and continue through the product's existing server/UI safeguards:

- publish or unpublish;
- delete nontrivial project content;
- prepare external guest messages;
- change public availability;
- exports that can disclose project content;
- operations that create a new uploaded derivative;
- future collaborator, permission, backup-restore, bulk-studio, external-upload, or spending tools.

V28.0 does not register collaborator changes, backup restoration, bulk studio operations, direct external upload, payment, or message-dispatch tools.
