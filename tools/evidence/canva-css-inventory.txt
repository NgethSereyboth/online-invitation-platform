# the caveats that make this table safe to use
* Canva's row is the marketing homepage, not the editor. The editor needs a login and was
  deliberately not entered. One of Canva's sheets did not come back at all:
  https://static.canva.com/web/2f6666decdbd610e.ltr.css -> Protocol error (Network.getResponseBody): No data found for resource with given identifier
  so Canva's row is a lower bound.
* The two pages are different pages. Ratios here are order-of-magnitude readings, not a
  like-for-like byte comparison; the one number that is directly comparable is !important,
  because it is a count of declarations the project controls.
