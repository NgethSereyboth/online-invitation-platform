shows closing it changed nothing else.

The gate only mechanically checks a fenced block with exactly one leading '$ '
line, and it used to drop every other block with a bare 'continue'. So a report
could carry any number of uncheckable blocks and still print 'still skipped 0'.
The rules for checking are unchanged; the blocks it cannot check are now counted,
named, and printed.
